# ردپا

بازی گروهی و تیمی سرنخ یک‌کلمه‌ای، به فارسی، برای بازی آنلاین با گوشی.

## دانلود
- **اندروید:** [آخرین نسخه‌ی APK](https://github.com/arttapart/radpa/releases/latest/download/radpa.apk)
- **نسخه‌ی وب (آیفون و هر مرورگری):** https://arttapart.github.io/radpa/

## روند بازی
1. میزبان اتاق می‌سازد و کد ۴ رقمی یا QR را به بقیه نشان می‌دهد.
2. بازیکن‌ها خودکار به دو تیم تقسیم می‌شوند؛ میزبان با زدن روی اسم‌ها جابه‌جایشان می‌کند و می‌تواند یار ربات اضافه کند.
3. اول هر نوبت سه واژه به سرنخ‌دهنده‌ها نشان داده می‌شود و انتخاب بیشترشان واژه‌ی اصلی می‌شود.
3. در هر نوبت، یک نفر از تیم حدس‌زن است و واژه را نمی‌بیند. هم‌تیمی‌هایش هر کدام یک کلمه سرنخ می‌نویسند.
4. سرنخ‌های تکراری یا خیلی شبیه خودکار خط می‌خورند.
5. تیم حریف سرنخ‌ها را می‌بیند و خط می‌زند؛ سرنخی حذف می‌شود که همه‌ی حریف‌ها خطش بزنند. با تأیید همه‌ی حریف‌ها، سرنخ‌ها به حدس‌زن می‌رسد.
6. حدس درست = ۱ امتیاز. اشتباه، «نمی‌دانم» یا تمام شدن وقت = ۰. حدس نزدیک (جمع، غلط تایپی) به رأی همه گذاشته می‌شود.

## بانک واژه
واژه‌ها در فایل [`public/words.txt`](public/words.txt) هستند و اپ موقع ساختن هر اتاق آخرین نسخه را از اینترنت می‌گیرد؛ پس برای تغییر واژه‌ها **نصب دوباره لازم نیست**.
- برای ویرایش: روی GitHub فایل را باز کن، آیکون مداد را بزن، تغییر بده و Commit کن.
- هر خط یک واژه. اگر بعد از واژه «:» بگذاری و چند کلمه با «،» بنویسی، ربات‌ها از آن‌ها سرنخ می‌دهند.
- خط‌هایی که با # شروع می‌شوند فقط گروه‌بندی پنهان برای متنوع شدن سه پیشنهاد هستند.

## فنی
- رابط: HTML/CSS/JS ساده با Vite، فونت وزیرمتن، کاملاً راست‌به‌چپ.
- اندروید: Capacitor.
- شبکه: Supabase Realtime (Broadcast + Presence). گوشی میزبان مرجع حالت بازی است؛ جدول دیتابیس لازم نیست.
- لایه‌ی شبکه در `src/net.js` جداست؛ برای رفتن به سرور خودتان فقط یک ترنسپورت تازه با همان رابط بنویسید.
- تست محلی بدون اینترنت: `npm run dev` و باز کردن چند زبانه با `?net=local`.

```bash
npm install
npm test
npm run dev
```

ساخت APK و انتشار وب خودکار با GitHub Actions انجام می‌شود (`.github/workflows/build.yml`).
